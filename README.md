## ▶️ Running a Program

Run commands from the repository root. Quote the path when it contains spaces.

```bash
python "python-learning/02.Basics/01_variable.py"
python "Python-Projects/Calc2.py"
```

Use the Python interpreter installed on your system. Some programs that read or write files may expect their sample text files to be available at the paths used in the code.
